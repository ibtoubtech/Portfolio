# Portfolio — Ibrahima Toubbou Bah

Portfolio professionnel responsive en français, conçu en HTML, CSS et JavaScript vanilla. Aucun outil de compilation n'est nécessaire.

## Aperçu local
1. Décompresser le dossier.
2. Ouvrir `index.html` dans un navigateur.

Pour un aperçu plus fidèle, lancer un serveur local depuis ce dossier :
```bash
python3 -m http.server 8000
```
Puis ouvrir `http://localhost:8000`.

## Déploiement ultérieur
Le site peut être déployé comme site statique sur GitHub Pages, Netlify, Vercel ou un hébergement Web classique. Il suffit de publier les fichiers `index.html`, `styles.css` et `script.js`.

## Avant publication
- Vérifier le numéro de téléphone, le courriel et le lien LinkedIn.
- Ajouter les liens GitHub des projets, si les dépôts peuvent être partagés.
- Ajouter un CV PDF si souhaité.
- Vérifier les intitulés exacts et les dates du parcours.
- Les illustrations de projets sont conceptuelles; elles ne sont pas des captures d'écran réelles.
- Les polices Google Fonts nécessitent une connexion Internet; des polices de secours sont prévues.

## Fichiers
- `index.html` : contenu et structure
- `styles.css` : mise en page responsive et styles
- `script.js` : menu mobile et année automatique
